# Рекомендательная система анализа состояния посевов на основе данных дистанционного зондирования

## Описание проекта

Данный проект представляет собой веб-ориентированную систему для анализа состояния сельскохозяйственных полей пшеницы на основе спутниковых или БПЛА-снимков в формате TIF. Основная цель системы — оценка состояния посевов пшеницы и формирование рекомендаций по дифференцированному внесению азотных удобрений.

В основе работы системы лежит расчет вегетационных индексов (ChlRI, NDVI, PRImod), которые позволяют оценивать состояние растительности по спектральным характеристикам изображений. На основе рассчитанных значений выполняется сегментация поля на зоны с различным уровнем детализации.

Система поддерживает работу как с пользовательскими гиперспектральными и мультиспектральными изображениями, так и со спутниковыми данными. Пользователь может задавать параметры анализа, например, фазу роста растений, пространственное разрешение и количество зон сегментации. Результатом работы являются карта состояния посевов и рекомендации по внесению азота.

## Основной функционал

- загрузка и обработка спутниковых и пользовательских снимков
- расчет вегетационных индексов (ChlRI, NDVI, PRImod)
- сегментация поля на зоны различного состояния
- учет агрономических параметров (фаза роста, разрешение и др.)
- формирование рекомендаций по внесению азотных удобрений
- система аутентификациии и авторизации пользователей

## Архитектура проекта

Проект разделен на две части:

- **backend** — серверная часть (Python, FastAPI), отвечает за обработку данных, расчет индексов, работу с БД и бизнес-логику
- **frontend** — клиентская часть (Vue.js), отвечает за интерфейс пользователя, отправку запросов и визуализацию результатов

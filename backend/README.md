# Backend

Серверная часть проекта реализована на FastAPI и отвечает за основную бизнес-логику: обработку спектральных снимков, расчет вегетационных индексов, сегментацию сельскохозяйственных полей, работу с базой данных и систему аутентификации пользователей.

---

## Запуск backend части проекта

### 1. Создание виртуального окружения и установка зависимостей

Переходим в директорию проекта, содержащую серверную часть приложения:

```
cd backend
```

Перед началом работы необходимо создать виртуальное окружение и установить зависимости проекта:
```
python -m venv venv
```
Активируем окружение:
```
venv/scripts/activate
```
Далее устанавливаем Poetry (если он еще не установлен):
```
pip install poetry
```
Устанавливаем зависимости проекта:
```
poetry install
```
---

### 2. Настройка переменных окружения

Перед запуском необходимо создать файл `.env` в корне backend.

За основу используется файл `.env.example`.

В нем необходимо заполнить параметры подключения к базе данных PostgreSQL:
```
PG_USER=
PG_PASSWORD=
PG_HOST=
PG_PORT=
PG_DBNAME=
```
При необходимости можно задать дополнительные параметры конфигурации.

База данных может быть развернута локально либо, например, через Docker.

---

### 3. Генерация ключей JWT

Для работы системы аутентификации необходимо сгенерировать ключи подписи токенов:
```
poetry run python app/generate_keys.py
```
После выполнения команды будет создана папка:

`app/keys/`

Внутри должны находиться файлы:

- jwt-private.pem
- jwt-public.pem

При необходимости папку можно создать вручную и добавить ключи самостоятельно.

---

### 4. Запуск сервера

После выполнения всех предыдущих шагов запускаем сервер командой:
```
poetry run uvicorn app.main:app
```

Если проект запускается в режиме разработки, можно использовать автоматический перезапуск сервера при изменении кода:
```
poetry run uvicorn app.main:app --reload
```
---

## Структура backend проекта

- `app/config` — конфигурация системы и параметры приложения
- `app/core` — основная логика обработки изображений и расчет вегетационных индексов
- `app/database` — модели и работа с PostgreSQL
- `app/routes` — API маршруты (авторизация, загрузка, обработка данных)
- `app/services` — бизнес-логика и вспомогательные сервисы
- `app/utils` — утилиты и вспомогательные функции
- `app/keys` — JWT ключи для подписи токенов
